# Зеркало себя — Design System v1

## Brand essence

**Зеркало себя** — закрытый цифровой инструмент самоисследования по дате рождения.

Не гадание. Не терапия. Не развлечение.  
А премиальный персональный документ о внутренней архитектуре человека.

Методология внутри: Система Цифрового Кода (мастер Альберт Вяземский).

---

## Positioning

```
Бесплатно:   первый слой формулы (5 чисел)
Платно:      Большое исследование — персональный PDF-разбор
После:       3 вопроса по своему разбору
```

## Product metaphor

```
Зеркало → Формула → Карта → Исследование
```

Один экран — одна идея. Никаких параллельных нарративов.

---

## Physical metaphor

**Закрытый документ высокой ценности.**  
Material: матовая бумага + тиснёная золотая фольга.  
Depth: карточная структура с тонкими бордюрами, без тяжёлых теней.

---

## Anti-patterns (запрещено в UI)

- "Миссия души" как главный продающий заголовок
- "Предназначение" как прямое обещание
- "Исцеление", "терапия", "диагностика"
- "Кармическая судьба", "карма заставит"
- Обилие лун, звёзд, магических символов
- Кислотные градиенты
- Инфобизнес-визуал
- Перегруженные экраны
- Таро-стиль

## Self-critique framework (Open Design)

Перед каждым экраном проверять:

1. **Philosophy** — Соответствует ли сути продукта?
2. **Hierarchy** — Понятно ли, куда смотреть и что делать?
3. **Detail** — Нет ли дешёвых элементов, случайных иконок?
4. **Function** — Можно ли дойти до оплаты по этому флоу?
5. **Innovation** — Есть ли ощущение собственного продукта?
